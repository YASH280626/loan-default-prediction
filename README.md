# Loan Default Prediction

A machine learning project that predicts whether a borrower is likely to default on a loan.

## Objective

Build and evaluate machine learning models for loan default prediction using exploratory data analysis, feature engineering, preprocessing, and classification algorithms.

## Planned Workflow

- Data Understanding
- Exploratory Data Analysis
- Feature Engineering
- Data Preprocessing
- Logistic Regression Baseline
- Model Comparison
- Hyperparameter Tuning
- Model Evaluation
- Model Interpretation
- Deployment

## Dataset

The project uses a loan default dataset containing borrower, loan, credit, and property-related information.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
